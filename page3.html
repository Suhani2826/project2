My Future Career: Web Development

Why I want to build for the web, and how I plan to get there.

Why Web Development?

Almost every business today depends on its website or app. A web developer is the person who turns an idea into something customers can actually use. Because I study both business and technology, I want a career where I understand what a company needs and can also build the product that meets that need.

Web development is also one of the few fields where you can see your work immediately. You write a few lines of code, refresh the browser, and your idea is on the screen. That fast feedback is what made me enjoy this course.

My Roadmap

  1. Learn HTML: master the structure of web pages, which is what this course starts with.
  2. Add CSS and JavaScript: learn to style pages and make them interactive.
  3. Build real projects: create websites for student clubs, small businesses and my own ideas, and keep them on GitHub.
  4. Become a web developer: land an internship, then a full-time role on a product team.

What a Web Developer Does

Front-end developer
Builds the parts of a website that people see and click, using HTML, CSS and JavaScript.
Back-end developer
Writes the server code and databases that store data and make the site work behind the scenes.
Full-stack developer
Works on both the front end and the back end of a project.

Skills I Will Need

  • Clean, valid, accessible HTML
  • Responsive design with CSS
  • Programming with JavaScript
  • Version control with Git and GitHub
  • Clear communication with designers, managers and clients

Where I Want to Be in Five Years

By the time I graduate in 2029, I want a portfolio of real projects and at least one internship behind me. Five years from now, I see myself working as a developer on a team that builds products for customers around the world, using both my technical skills and my business education.
